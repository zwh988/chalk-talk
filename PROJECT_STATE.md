Rating R5 (`ratingConfig.ts` / `control.ts` / `rating.ts` / `Info.tsx`; checked against a hand calculation and a simulation, not compiled in the project): (1) Finishing no longer uses length buckets. Every chance (first visit after own break excluded; solo included) has an expected run-out chance p = 0.85^(balls on the table) × 0.6 for a Hard opening × 0.7 for a Problem table (clamped .02–.98), so p is about 52% for 4 balls on an Easy, Clean table. A run-out counts 1−p and a failed chance counts p, so long runs pay a lot and cost little, short runs the reverse. Score = weighted success rate S/(S+F), 0 at 10% and 100 at 50% (the level p is set at, about top pro); needs 5 chances (`MINF`). The Finishing card on Review is unchanged (descriptive buckets from `fin.len`); `controlStats.fin.ch` carries the per-chance records. In the simulation a per-ball reliability of .6 / .75 / .85 / .9 scores about 13 / 51 / 91 / 99 (sd about 13–20 at 40 chances) and a tougher mix of chances moves the score by only a few points. (2) Anchors: Shotmaking Easy pot rate 0 at 60% (was 75%, top still 97%); Decision 0 at 75% and 100 at 97% (was 85% / 99%); Defence forced-error rate 0 at 10% and 100 at 60% (was 5% / 35%).
